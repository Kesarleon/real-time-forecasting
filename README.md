# Real-Time Forecasting

Este proyecto realiza un pronóstico en tiempo real de datos financieros utilizando Python. Obtiene datos de una API pública (Yahoo Finance), aplica un modelo ARIMA para el pronóstico y muestra los resultados en un dashboard de Streamlit.

## Cómo ejecutarlo

1.  Instala las dependencias:
    ```bash
    pip install -r requirements.txt
    ```

2.  Ejecuta la aplicación de Streamlit:
    ```bash
    streamlit run app.py
    ```
